# Number Analyzer CLI

A command-line application built using Python to analyze numbers entered by the user.

## Features
- Identifies positive, negative, and zero numbers.
- Checks whether a number is even or odd.
- Calculates square and cube.
- Checks whether a number is divisible by 5.
- Handles invalid inputs using try-except.
- Supports analyzing multiple numbers using a while loop.

## Concepts Used
- Variables and data types
- User input and type conversion
- Conditional statements
- Arithmetic operators
- While loops
- Exception handling

## How to Run

```bash
python number_analyzer.py
```

**Language:** Python 3
